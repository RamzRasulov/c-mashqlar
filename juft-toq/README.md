## Misol sharti

Sonning juft yoki toqligini aniqlang. Agar juft bo‘lsa `juft` so‘zini return qiling. Agar toq bo‘lsa `toq` so‘zini return qiling.

## Namuna

Input: 4
Output: juft

Input: 7
Output: toq

Input: 18
Output: juft

## Maslahat

Sonning juft yoki toq ekanligini aniqlash uchun uni 2 ga bo‘lish kerak.

Agar 2 ga bo‘lganda qoldiqsiz bo‘lsa, demak juft son:
`4, 10, 18`

Agar 2 ga bo‘lganda qoldiq qolsa, demak toq son:
`3, 11, 21`
